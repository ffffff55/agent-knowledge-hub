# 鹈鹕骑自行车 SVG 动画设计

## 目标

创建一个可直接在浏览器打开的独立 HTML 页面，以 SVG 绘制一只鹈鹕骑自行车的 2D 循环动画。页面不依赖外部图片、字体、脚本或网络资源，也不修改现有控制台页面。

## 视觉与构图

- 使用轻松、温暖的绘本插画风格，鹈鹕与自行车是首屏主体。
- 主场景由内嵌 SVG 绘制，采用清晰的轮廓、珊瑚橙车架、薄荷色路面和浅色海岸背景。
- 场景包含简单的海岸线、云和植被作为环境层次，留出足够空间突出骑行者。
- 页面在窄屏下保持主体完整可见，不产生横向溢出。

## 动画与交互

- 自行车轮子连续旋转，曲柄和踏板随之运动。
- 鹈鹕身体随踩踏轻微起伏，喙袋有克制的次级摆动。
- 背景云层与地面细节缓慢平移，形成前进感；动画整体无突兀跳变。
- 提供可键盘操作的暂停/继续按钮，并为按钮提供可访问名称。
- 尊重 `prefers-reduced-motion`：减少动态效果时停止持续运动，同时仍显示完整静态插画。

## 实现边界

- 交付文件：`python/web/pelican-bike.html`。
- HTML、样式、SVG 图形和少量动画控制逻辑全部内聚在此文件中。
- 使用 SVG 分组与 CSS 动画实现主要运动；不引入框架、依赖或构建步骤。
- 不修改 `python/web/index.html` 或其他现有、未提交文件。

## 验收标准

1. 文件可独立打开，页面上可见完整的鹈鹕、自行车和场景。
2. 自行车轮、踩踏动作和鹈鹕身体动画协调循环；背景有轻微移动。
3. 暂停/继续按钮可用鼠标和键盘操作。
4. 窄视口下画面仍完整可见；减少动态效果时保持静态画面。
5. 无外部资源请求，HTML/SVG 结构有效，浏览器控制台无脚本错误。
